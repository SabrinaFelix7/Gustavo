# 💕 Surpresa Romântica

Um pequeno site romântico feito com HTML, CSS e JavaScript para surpreender alguém especial.

## Como abrir

1. Extraia a pasta.
2. Abra a pasta no VS Code.
3. Abra o arquivo `index.html`.
4. No VS Code, você pode usar a extensão **Live Server** e clicar em "Go Live".
5. Também é possível simplesmente abrir o `index.html` no navegador.

## Como colocar suas fotos

Dentro da pasta `imagens`, coloque suas fotos e renomeie para:

- `foto1.jpg`
- `foto2.jpg`
- `foto3.jpg`

Depois, substitua cada bloco `.photo-placeholder` do `index.html` por:

```html
<img src="imagens/foto1.jpg" alt="Nossa foto">
```

Você pode repetir para as outras duas fotos.

## Como personalizar

No `index.html`, altere os textos para colocar:
- o apelido dele;
- uma lembrança de vocês;
- uma frase que só vocês usam;
- coisas que você realmente ama nele.

O botão "Ainda estou bravo 😠" foi feito para fugir do mouse/touch como uma brincadeira.

Não precisa de internet para o funcionamento do site, mas a fonte usada no visual é carregada do Google Fonts quando houver conexão.
